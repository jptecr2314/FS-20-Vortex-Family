# FS-20 Vortex Family 0.6.9

Experimental A/B/C/T/NA family update with opt-in matching-install multiplayer,
corrected NA surfaces/cannon doors and six liveries, A/C pitch-governor and AI
planning updates, and a fuel/payload/deck-wind-aware A/C/NA takeoff advisor.

reservations, flight and resale retain the exact variant, preventing A-to-NA
resale conversion while leaving faction supply sharing optional.

Version numbering resumes at 0.6.9 using tag fs20-v0.6.9. The historical v6.0.7
release is preserved. Existing 6.0.7/6.x installations require one explicit
version selection/reinstallation; later corrected-line updates compare normally.

Nuclear Option 0.34.6, Blueprinter 2.1.1 and BepInEx 5 required. All multiplayer
participants need this exact build and must opt in. Native authentication and
simulation authority remain in place. Real two-installation Steam acceptance,

remain pending. See QA.md. No game installation is performed by publication.
