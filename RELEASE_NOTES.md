# FS-20-Vortex-Family 0.4.1

Single-player FS-20A and FS-20C variants alongside the stock B, with a native-style selector, C tailhook and optional shared A/B/C stock in one plugin. C: 110/165 kN; A/C: up to +11 G. Online sessions are blocked.

Install prerequisites separately. Target game 0.34.6. Select GitHub prerelease; attach FS-20-Vortex-Family.zip first. Single-player only; online menu, client connects and network-listening hosts are blocked. Gameplay features have been tested in-game by the author during development. Automated policy, inventory, saved-setting and single-player guard checks passed. Source is in this repository; no game assets are bundled. Substantial AI assistance is declared.
