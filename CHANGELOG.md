# 0.4.0 — prepared 2026-11-08

Adds FS-20A and FS-20C alongside the stock B, with a native-style selector, C tailhook and optional shared A/B/C stock in one plugin. C: 110/165 kN; A/C: up to +11 G.

0.4.0 merges aircraft and shared-stock code into one plugin. F1 Inventory > Shared airframe stock selects pooled or separate native counters without changing A/B/C availability. Legacy standalone plugin is incompatible and must be removed. Includes prior hook, landing and UI changes. Live validation remains pending.

First public-candidate preparation; private prototypes are not prior public releases.
